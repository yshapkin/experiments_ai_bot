# experiments_ai_bot

This repository contains one or more Node.js projects intended for deployment to
Microsoft Azure.

## Repository structure

```text
.github/      GitHub repository configuration
docs/         Documentation
plans/        Append-only agent workflow plans and execution ledgers
src/          Functional code base
test/         Unit tests
deployment/   Infrastructure as Code (IaC) use Bicep
```
